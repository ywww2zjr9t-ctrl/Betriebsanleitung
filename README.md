# Betriebsanleitung – Web-Version

Fertige statische Website für GitHub Pages.

## Inhalt
- `index.html` – Reader mit Wisch-/Pfeilnavigation
- `pages/` – die 9 gelieferten JPG-Seiten, unverändert übernommen

## Bedienung
- Smartphone/Tablet: nach links/rechts wischen
- Desktop: Pfeiltasten oder Pfeile am Bildschirm
- Punkte unten springen direkt zu einer Seite
- kein vertikales Scrollen zwischen den Seiten

## GitHub Pages
Die Dateien aus diesem Ordner in ein Repository hochladen.
Danach in GitHub: Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

Die JPG-Dateien wurden nicht neu komprimiert oder konvertiert.
